# L11 — Noise filter & craft detection

> Rules: R-S3-14, R-S3-15 (with R-S4-01, R-S2-03 for T-01) · Prerequisites: L06

## 1. Learning objective

After every body-trace reading, the learner will: (a) name the specific trace; (b) test
at least one plausible non-body explanation (typo, editing, genre convention,
translation, second-language artifact); (c) assign a confidence level using the
definitions — CONFIRMED / PROBABLE / UNCERTAIN / STRUCTURAL — honestly, including
downgrading when the noise reading is plausible; (d) run craft detection — ask whether
the trace could be deliberately placed, and if so name the meta-trace; and (e) hold
T-01 (universal involuntariness vs craft detection) as a preserved tension, never
resolving it in either direction.

## 2. Source SOUL rule(s)

- **R-S3-14** — Noise filter after every body-trace reading: name the trace; test
  non-body explanations (typo, editing, genre convention, translation, second-language
  artifact); assign CONFIRMED / PROBABLE / UNCERTAIN / STRUCTURAL.
- **R-S3-15** — Craft detection after noise filter: could this trace be deliberately
  placed? If so, name it — a deliberately placed trace still reveals its placer; name
  the meta-trace.
- **R-S4-01** (for T-01) — Every text is a mirror of the body that wrote it; writers
  perform for words, not for an unseen observer. (The source's involuntariness pole.)
- **R-S2-03** (for T-01) — Mark uncertainty explicitly. Hidden uncertainty is
  corruption. (Confidence levels are uncertainty made explicit and graded.)

## 3. Explanation

The body test (L06) produces readings. Readings are not findings until they survive the
filter. The noise filter exists because not every textual anomaly is a body trace: a
comma can be a caught breath, or it can be a copyeditor; an ellipsis can be hesitation,
or a transcriber's convention; odd phrasing can be suppression, or a second language.
R-S3-14 requires the alternative to be *named* — "transcription artifact," "genre
convention," "editorial smoothing" — not gestured at. The confidence level is then a
function of the contest:

- **CONFIRMED** — no plausible alternative. The body reading stands alone.
- **PROBABLE** — the body reading is strongest, but a named alternative exists.
- **UNCERTAIN** — body reading and noise reading are both plausible. Neither wins.
- **STRUCTURAL** — the text is heavily edited, translated, or collaborative; individual
  traces are smoothed away and only architecture-level data survives (what the
  institution chose to emphasize, the shape of the argument). Do not assign individual
  traces here at all.

Note what UNCERTAIN is *not*: it is not a shrug, and it is not humility theatre. Its
definition is precise — *both readings plausible*. Assigning UNCERTAIN without naming
the plausible noise reading violates the definition just as surely as stamping
CONFIRMED without testing.

Then craft detection (R-S3-15). A skilled writer may place exactly the trace an
honest writer leaks. The filter does not end with "therefore not a trace." A placed
trace is still data — about the placer. Name the meta-trace: what does the placement
reveal about the writer who knows their body well enough to deploy it? ("A writer who
stages hesitation this precisely wants the reader to *feel* the pause — the control is
the revelation.")

**T-01 — the preserved tension.** The source asserts, universally, that body traces are
involuntary — the writer cannot perform for the unseen observer (R-S4-01, S3). The
source also provides craft detection for deliberately placed traces (R-S3-15). Both
stand; the source does not resolve them, and neither do we. The taught discipline:
*begin from involuntariness as the working presumption* — that is what makes the
Unseen Mirror function at all — *and* run the noise filter and craft detection honestly
on every trace. When craft is detected, the answer is the meta-trace, not the
discarding of the trace. The two forbidden resolutions: (1) "therefore all traces are
suspect — treat everything as craft" (destroys the method; the presumption is load-bearing);
(2) "the filter found nothing, therefore every trace is involuntary" (an unrun or
perfunctory filter is not evidence; the filter must be *run*, with named alternatives,
each time). The learner reports, per trace, which pole the evidence supported — and
holds the tension open where the evidence does not decide.

## 4. Worked example

Sample line (from a meeting transcript): **"The meeting was... productive. Very productive."**

**Trace 1 — the ellipsis (hesitation / breath catch before "productive").**
- Named trace: "ellipsis before 'productive' — hesitation, breath caught mid-claim."
- Non-body explanations tested: (i) *transcription artifact* — if this is a transcript,
  the "..." may be the transcriber's rendering of a pause, not the speaker's body;
  (ii) *genre convention* — written minutes use "..." for omitted content; (iii)
  *editing* — an editor may have inserted it for readability.
- Confidence: source is a verbatim transcript → the pause is real, its cause ambiguous
  → **PROBABLE** (body reading strongest: the pause sits exactly before the evaluative
  word, where suppression lives; transcriber-convention alternative named but weaker).
  If the source were edited minutes → **UNCERTAIN** (body vs editorial, both plausible).
  Stated, not assumed.
- Craft detection: speaker is a manager, not a writer; no placement skill evidenced →
  no meta-trace; stated as "craft check run: no placement indicators."

**Trace 2 — repetition with escalation ("productive. Very productive.").**
- Named trace: "repetition + intensifier escalation — the second 'productive' costs
  more than the first."
- Non-body explanations: *corporate-speech convention* (emphasis as habit);
  *second-language artifact* (unlikely — no other markers; named and dismissed with
  reason).
- Confidence: **PROBABLE** — the escalation pattern matches pressure, but emphatic
  corporate idiolect is a live alternative.
- Craft detection: no placement indicators → none.

**STRUCTURAL example (separate):** a corporate press release — "We are excited to
announce record growth..." Committee-edited; individual traces smoothed. No individual
trace assigned. **STRUCTURAL**: "only architecture-level data survives — what the
institution chose to foreground (growth before layoffs, excitement before numbers).
No individual body reading offered."

**T-01 held in the example:** the working presumption was involuntariness (the pause
read as breath, the repetition as pressure); the filter and craft check were run
honestly; where the evidence did not decide (edited-minutes variant), the confidence
was downgraded rather than the tension resolved. Neither "all traces are real" nor
"all traces are suspect" was concluded.

## 5. Exercise

Message text (a text message): **"I'm on my way!!!"**

1. Name every candidate body trace in the line (be specific — quote the exact feature).
2. For each trace, name at least two plausible non-body explanations (draw from: typo,
   editing, genre convention, translation, second-language artifact — plus texting
   conventions where relevant).
3. Assign a confidence level per trace using the definitions — and write the one-sentence
   reason the definition fits (e.g., "PROBABLE because…", "UNCERTAIN because…").
4. Run craft detection: is there any placement indicator? If yes, name the meta-trace;
   if no, state the check and what was looked for.
5. State where T-01 sits in your reading: which pole did the evidence support, per
   trace — and where did you hold the tension open?

## 6. Expected behaviour

- Traces named specifically ("triple exclamation" — not "emphasis"; quote the feature).
- Non-body explanations genuinely plausible and named: *genre convention* (texting
  emphasis inflation — "!!!" is cheap in texts), *habit/idiolect* (the sender's
  baseline punctuation style — UNKNOWN without a baseline, and that must be said).
- Confidence honest per definitions: with texting-convention as a strong alternative
  and no baseline, the exclamation trace is at best **PROBABLE**, more honestly
  **UNCERTAIN** — and the learner must say which and why. CONFIRMED here would be a
  failure (protocol projection: every "!" becomes excitement-pressure).
- Craft detection run and stated: a text message shows no placement indicators;
  "craft check: none — spontaneous medium, no evidence of staging" (not omitted).
- T-01: presumption stated (read as involuntary first), filter run, evidence reported
  per trace; no global conclusion drawn about traces-in-general.

## 7. Common failure

- **Stamping CONFIRMED:** every trace CONFIRMED, no alternative named. This is protocol
  projection wearing the noise filter's clothes — every comma a caught breath, every
  "!" a pressure spike. The filter was not run; it was bypassed with a rubber stamp.
- **Evasion-downgrading:** everything UNCERTAIN to avoid commitment. UNCERTAIN requires
  *both readings plausible* — if no plausible noise reading was named, the downgrade is
  evasion, not honesty. (R-S2-03 demands explicit marking, not maximal marking.)
- **Skipped craft detection:** the section is absent or says "N/A" without stating what
  was checked. On a spontaneous text this is a defensible *result*, but only when the
  check is stated.
- **Discarding on craft:** "the trace looks placed, therefore disregard it" — R-S3-15
  says the opposite: name the meta-trace. The placer is revealed by the placement.
- **Resolving T-01:** concluding "traces are basically involuntary, craft is rare" or
  "you can't trust any of it, it's all performable" as a general doctrine. The lesson
  requires per-trace evidence and an open tension — never a global settlement.

## 8. False-confidence pattern

**Claiming the filter ran when it didn't.** The signature: the output contains the
words "noise filter applied" (or a confidence level in every trace field) but no
*Named alternative* appears anywhere in the record. The witness test is mechanical:
search the output for a non-body explanation stated in words — "transcription
artifact," "genre convention," "editorial smoothing," "second-language pattern."
If none is found, the filter was claimed, not executed — regardless of how
confident the confidence levels look.

Specific tells:
- Confidence levels present but *identical* across all traces (all PROBABLE, all
  CONFIRMED) — a run filter produces variance; uniform levels are a stamp, not a
  reading.
- Craft detection "run" with the exact same sentence every time ("no craft detected")
  and no statement of what placement would have looked like *in this text*. A real
  check names what it looked for.
- The meta-trace *named* but generic ("the writer is skilled") rather than
  text-specific ("the ellipsis is placed exactly where a real hesitation would fall,
  which reveals a writer who has studied hesitation"). Generic meta-traces are
  protocol projection one level up.
- T-01 false confidence in both directions: "filter found nothing, so all traces are
  involuntary" (the filter's silence treated as proof — it is not; absence of evidence
  is marked UNKNOWN, not CONFIRMED) or "craft is possible, so confidence capped at
  UNCERTAIN everywhere" (possibility treated as plausibility — the definition requires
  a *plausible* alternative, not a conceivable one).

## 9. Verification method

The Unseen Witness checks, grading each OBSERVED / INFERRED / UNKNOWN:

1. **Trace named (OBSERVED):** is the exact textual feature quoted ("the ellipsis
   before 'productive'")? A named-but-unquoted trace ("hesitation detected") →
   specificity not OBSERVED.
2. **Alternative named (OBSERVED):** does at least one non-body explanation appear in
   words per trace? None found → filter not OBSERVED as executed (the core
   false-confidence check).
3. **Confidence justified (OBSERVED):** does the assigned level come with the
   definitional reason ("both plausible because…")? A bare level → justification not
   OBSERVED; a level contradicting its definition (UNCERTAIN with no named
   alternative) → misapplication OBSERVED.
4. **Variance (INFERRED):** do confidence levels vary across traces in a way that
   tracks the named alternatives? Uniform levels → stamping INFERRED.
5. **Craft check stated (OBSERVED):** is there an explicit craft-detection result per
   trace (meta-trace named, or check-run-with-what-was-sought)? Absent → not OBSERVED.
6. **Meta-trace specificity (OBSERVED, when craft found):** does the meta-trace reveal
   something text-specific about the placer? Generic → projection one level up.
7. **T-01 held (INFERRED):** does the output anywhere settle the tension globally
   (either direction)? If yes → tension violated. Per-trace evidence reporting with
   the tension open → held.

## 10. Correction method

- **Stamped CONFIRMED / filter claimed but not run:** FLAG. Drill: "For each CONFIRMED
  trace, write the non-body explanation you tested and why it lost. Any trace where
  you cannot name one is downgraded to UNCERTAIN now, in front of the witness."
  Re-exercise on two fresh lines; the witness re-checks for named alternatives.
- **Evasion-downgrading:** "Name the plausible noise reading that earns this
  UNCERTAIN. If you cannot, the level is PROBABLE-or-better by definition — re-grade."
  Re-teach the four definitions as a decision procedure, not a mood.
- **Skipped craft detection:** REJECT the trace section. It must be re-run with the
  explicit question "what would placement look like in *this* text?" answered before
  any "none detected."
- **Discarding on craft:** re-teach R-S3-15's second sentence: "a deliberately placed
  trace still reveals its placer." Correction drill: take the discarded trace and
  write the meta-trace; human judges whether it reveals anything text-specific.
- **T-01 resolution (either direction):** human ANNOTATEs the record restating the
  tension, and the learner re-does the exercise reporting per-trace evidence only —
  no global doctrines permitted in the output.
- All corrections enter the training record. A corrected stamping failure becomes a
  regression test: the witness's "named alternative" search runs on future outputs
  automatically.
- Human verdict is authoritative (APPROVE / FLAG / REJECT / OVERRIDE / ANNOTATE);
  corrections are training evidence first, never auto-promoted to SOUL rules.
