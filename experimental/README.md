# experimental/

Intentionally empty in v1.0.0.

Experimental material — notably π/TGF-style metrics and any future
unvalidated evaluation machinery — is excluded from the v1.0 skill
contract by design. Experimental evidence must never be presented as
normative, must never override witness evidence, and must never enter
the skill's operating rules.

If experimental records are ever retained here for historical
reproducibility, each must carry an explicit label stating it is
non-normative and not part of the validated skill.
